# Neon Coast Studio

[![make.fun · gta6-cover-art-01](https://make.fun/badge/gta6-cover-art-01.svg)](https://make.fun/bounty/gta6-cover-art-01) [![rank](https://make.fun/badge/gta6-cover-art-01/Brengsek27/gta6-cover-art-01-r4/rank.svg)](https://make.fun/bounty/gta6-cover-art-01/leaderboard) [![reward](https://make.fun/badge/gta6-cover-art-01/Brengsek27/gta6-cover-art-01-r4/reward.svg)](https://make.fun/bounty/gta6-cover-art-01)

Neon Coast Studio is a local-first cover-art editor for turning ordinary photos into vivid, multi-panel stories with poster lettering, caption chips, badges, and export-ready composition.

## Run it

Run `node serve.ts`, open the local URL, load a photo, choose a layout and color story, then export a PNG.

Anton and Pacifico are bundled in `app/fonts/` under the SIL Open Font License 1.1 and loaded locally for cover lettering.
